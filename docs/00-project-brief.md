# 00 项目简介

## 一句话说明

六库生活圈是一个本地便民信息黄页小程序，帮助居民快速查找商家电话、招聘、租房和上门服务信息，也帮助本地商家获得基础曝光和推广位。

## 核心价值

- 居民：少翻群聊，快速找到电话、位置、招聘、租房和常用服务。
- 商家：展示电话、地址、营业信息、招聘和活动。
- 运营者：人工审核、更新过期内容、安排置顶推荐、处理纠错投诉。

## 首版策略

首版不追求交易闭环，而是验证信息供给、审核效率、商家推广意愿和本地用户使用频率。技术上先做本地假数据 UI 原型，页面和服务层保持可迁移到云开发的结构。

## 运营重点

- 信息真实。
- 更新及时。
- 联系方式清楚。
- 违规内容不上架。
- 推广位和置顶有到期管理。
