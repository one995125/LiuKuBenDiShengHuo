# 06 风险与注意事项

## 运营风险

- 信息过期会影响用户信任，需要人工定期复核。
- 商家电话、微信、地址错误会带来投诉，需要纠错入口。
- 推广位收费如果没有到期记录，容易产生纠纷。

## 合规风险

- 手机号、微信号、地址和图片可能涉及个人信息，必须准备隐私保护指引。
- 招聘信息不得承诺就业，不得做收费介绍工作。
- 租房信息不得包装成中介撮合，需提醒用户自行核实。
- 医疗、药品、金融、招聘、房产等类目上线前必须核对微信小程序服务类目和资质要求。

## 技术风险

- 本地 storage 不可作为正式数据源。
- 本地隐藏管理页没有生产安全性。
- 如果后续接入云开发，需要重新做 openid 数据隔离、集合权限、云函数权限校验、分页和索引。
- 三个云函数已可使用；当前主要风险转为集合权限、索引遗漏、云存储访问控制和多用户隔离验收不足。
- CloudBase 环境未来共享时，必须保留 `liuku_` 命名和来源 AppID 校验，不能只依赖环境级隔离。

## 上线前必须补齐

- 云开发或正式后端。
- 管理员 openid 白名单。
- 隐私协议和用户信息处理说明。
- 内容审核流程和投诉处理规则。
- 服务类目与资质核对。
