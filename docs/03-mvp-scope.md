# 03 MVP 范围

> 2026-07-22 当前范围：用户端采用“店、房、修、购”四个独立板块；只开放持照商家和合规出租房源受控投稿，招聘频道关闭。下方旧阶段条目若与本说明冲突，以本说明和 `docs/05-decisions.md` D013-D014 为准。

## 必须做

- 首页本地入口
- 商家黄页列表和详情
- 购物零售和上门服务独立列表（复用商家详情与审核链路）
- 租房列表和详情
- 我的页、本机收藏、浏览足迹、客服和私密纠错投诉
- 独立运营后台直接维护公开内容
- 隐藏运营页，只说明运营边界
- 本地 mock 服务层
- 隐私、招聘、租房、平台展示免责声明

## 可以后做

- 访问统计和运营报表
- 服务类目资质校验清单自动化
- 置顶到期自动下架
- 搜索热词和访问统计

## 明确不做

- 微信支付
- 在线下单
- 外卖配送
- 未经人工审核直接公开的投稿、发帖或公开评论
- 即时聊天
- 地图找店
- 用户自由发帖后自动展示
- 商家自助后台
- 积分会员
- 信息流社区
- 简历投递
- 房屋中介撮合
- 复杂推荐算法
