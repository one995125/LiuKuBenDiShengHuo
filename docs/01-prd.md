# 01 产品需求文档

> 2026-07-22 当前实施口径：商家黄页和出租房源开放受控投稿、人工审核后展示；招聘频道全部关闭。本文后续遗留的招聘展示、普通用户不可投稿等旧阶段描述，以本节和 `docs/05-decisions.md` 的 D013 为准。

## 当前上线范围

- 商家：公开展示开启；仅持营业执照主体可投稿；运营后台可录入，但必须完成同等材料与核验清单。
- 出租房源：公开展示开启；仅业主本人或备案中介可投稿；不包含出售、带看、签约和佣金结算。
- 招聘：公开展示、用户投稿、后台发布、推荐和 Excel 导入全部关闭；历史数据保留并下架。
- 首页板块：“店、房、修、购”分别进入到店商家、房屋出租、上门服务、购物零售；店/修/购共享商家详情和审核链路，板块由一、二级分类自动确定。
- 所有投稿先进入 `pending`，人工审核通过后生成正式内容；拒绝必须给出用户可见原因，重新提交生成新记录。
- 公开图片与私密核验材料严格分离。核验材料仅管理员访问，并在拒绝或公开内容下架/删除满一年后删除原文件。

## 1. 项目概述

六库生活圈面向六库本地居民、商家和运营者，提供到店商家、房屋出租、上门服务、购物零售和优惠活动的信息展示能力。

首版目标是做出可运营的微信小程序 MVP：用户可以浏览本地信息、搜索关键词、查看详情并私密提交纠错投诉；运营者通过独立后台录入、核验、发布、置顶、推荐和下架公开内容。

## 2. 产品定位

本项目是便民信息黄页，不是交易平台。首版只做：

- 信息展示
- 运营后台直接维护
- 推荐置顶
- 联系客服纠错

明确不做：

- 外卖配送
- 在线下单
- 微信支付
- 用户公开评论
- 未经人工审核直接公开的用户发布或投稿
- 即时聊天
- 地图找店
- 用户自由发帖后自动展示
- 商家自助后台
- 积分会员
- 信息流社区
- 简历投递
- 房屋中介撮合
- 复杂推荐算法

## 3. 目标用户

- 本地居民：查电话、找修理、看招聘、找租房、找常用服务。
- 本地商家：展示电话、地址、营业信息、招聘信息和优惠活动。
- 管理员/运营者：录入并核验信息、设置置顶推荐、处理投诉、更新过期内容和记录收费状态。

## 4. MVP 模块

### 首页

- 顶部搜索框，支持商家名、电话、服务关键词、岗位、位置。
- 四个一级入口：到店商家、房屋出租、上门服务、购物零售。
- 运营说明：公开内容均由运营者统一录入和维护。
- 本地精选：最多混合展示 6 条推荐商家、招聘、房源和优惠活动，支持自动轮播和手动滑动。
- 客服入口：用于纠错、投诉、商家合作。

搜索后使用搜索结果替换“本地精选”区域；清空搜索后恢复轮播。单条精选不自动轮播，多条内容约每 4.5 秒切换。

### 商家黄页

字段：

- 商家名称
- 所属分类
- 联系电话
- 微信号，可选
- 地址
- 营业时间
- 简介
- 图片，可选
- 标签，例如可配送、上门服务、24 小时、新店
- 是否推荐
- 是否置顶
- 发布时间
- 更新时间
- 审核状态

详情页首版只保留拨打电话、复制微信、联系客服纠错。

### 招聘信息

字段：

- 岗位名称
- 商家/公司名称
- 薪资范围
- 工作地点
- 工作时间
- 招聘人数
- 联系方式
- 岗位要求
- 发布时间
- 有效期
- 是否置顶
- 审核状态

首版不收简历、不做在线投递、不做劳务派遣、不做收费介绍工作。

### 房屋出租

字段：

- 标题
- 租金
- 位置
- 户型
- 面积，可选
- 图片
- 联系方式
- 房源说明
- 发布时间
- 有效期
- 是否置顶
- 审核状态

详情页展示免责声明：信息由发布者提供，平台仅作展示，用户需自行核实。

### 优惠活动

- 展示活动标题、商家名称、摘要、详细说明、起止日期、电话、微信和最多 3 张图片。
- 可选关联已收录商家；关联后详情页提供“查看商家”。
- 仅展示状态为 `published`、已开始且未过期的活动。
- 仅支持运营后台直接发布、编辑、下架和到期维护。
- 首版只提供联系商家，不提供优惠券领取、核销、支付或订单。

## 5. 页面结构

- 首页：分类入口和“本地精选”混合轮播。
- 商家列表页：按分类浏览，支持搜索和筛选。
- 维修商家页：按全部、家电、开锁、家政筛选上门服务。
- 商家详情页：电话、地址、营业时间、图片、简介和本机收藏。
- 招聘列表页：按最新/置顶展示招聘。
- 招聘详情页：岗位、薪资、地点、联系方式和本机收藏。
- 租房列表页：按最新/置顶展示房源。
- 租房详情页：租金、位置、户型、图片、联系方式和本机收藏。
- 优惠活动详情页：封面、商家、说明、有效期、联系方式、免责声明和本机收藏。
- 我的页：本机收藏、最近浏览、联系客服、私密纠错投诉、用户协议和隐私指引。
- 纠错与投诉：关联当前信息、选择类型、填写说明和联系方式。
- 管理后台：直接录入、编辑、置顶、推荐、下架，并查看和处理私密反馈。

用户端固定底栏保留四个全局入口：首页、商家、客服、我的。招聘、租房和上门服务作为首页信息入口下钻进入，列表和详情返回时回到上一级页面。

## 6. 数据状态

统一状态：

- `draft`：草稿，管理员编辑中
- `pending`：待审核
- `published`：已发布
- `rejected`：已拒绝
- `expired`：已过期
- `offline`：已下架

推广字段：

- `isTop`：是否置顶
- `topUntil`：置顶到期时间
- `isFeatured`：首页推荐
- `featuredUntil`：推荐到期时间
- `isPaid`：是否收费
- `paidType`：收费类型
- `chargeUntil`：收费到期时间
- `adminNote`：人工备注

## 7. 管理端需求

正式运营使用独立管理后台，功能包括：

- 直接录入和编辑公开信息
- 发布、下架或删除信息
- 设置置顶
- 设置首页推荐
- 设置过期/下架
- 标记是否已联系商家
- 记录收费状态和备注
- 查看纠错和投诉记录并标记已处理

管理后台使用 CloudBase Auth 登录、管理员白名单和服务端权限校验；隐藏小程序页只显示运营边界，不处理业务数据。

## 8. 变现方式

第一阶段不接微信支付，只记录线下收费：

- 商家基础收录免费
- 商家置顶按月收费
- 首页推荐位按周/月收费
- 招聘置顶按条/按周收费
- 房源置顶按条收费
- 商家图文代录入服务费
- 年费套餐：黄页收录 + 推荐位 + 招聘/活动发布

## 9. 合规与隐私

- 公开内容仅由运营者录入并核验后展示，普通用户不能投稿或公开评论。
- 公开电话、微信号、地址和图片必须由运营者确认来源与授权。
- 用户私密反馈及选填联系方式必须提供隐私说明且不得公开展示。
- 招聘只做信息展示，不收简历，不承诺就业。
- 租房只做信息展示，不做中介撮合。
- 医疗、药品、金融、招聘、房产等类目上线前需核对微信小程序服务类目和资质要求。
- 必须有投诉/纠错入口。
- 虚假、违法、低俗、侵权内容不得展示。
