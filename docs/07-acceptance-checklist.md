# 受控投稿版本验收清单

自动检查通过不等于已部署。完成本清单后，还要在微信开发者工具、体验版真机和 CloudBase 控制台分别留存证据。

## 用户端

- 首页、搜索、收藏筛选、路由注册均无招聘；旧招聘链接提示频道关闭，缓存和 mock 不显示招聘。
- 商家列表可进入固定商家投稿页；房源列表可进入固定出租房源投稿页；页面没有招聘类型选项。
- 商家必填名称、分类、区域、地址、营业时间、简介、电话、营业执照、经营场所照片和三项声明。
- 业主房源必填出租信息、公开图片、出租权证明和声明；备案中介额外必填营业执照、经纪备案和业主授权。
- 公开图片最多 3 张、核验材料最多 6 张，仅 JPG/PNG 且单张不超过 5MB；页面明确材料遮挡与可辨认范围。
- 弱网失败后草稿只归属当前 `openid + appid`，恢复网络可重试且幂等，不重复创建。
- “我的投稿”只显示当前账号的商家/房源投稿，包含状态、提交时间、拒绝原因和已发布入口。
- 被拒绝后重新提交会创建新记录，不修改原审核记录。
- 头像昵称可选，未填写也能投稿；头像昵称不作为资质证明。

## 云函数与权限

- `liuku_configs/channel_policy`：商家、房源三项开启；招聘三项关闭。配置读取失败时招聘仍关闭。
- 用户伪造 `type=job` 返回 `CHANNEL_DISABLED`；公开列表/详情请求招聘也返回相同稳定码。
- 投稿文件必须位于当前 `openid/请求标识/public` 或 `evidence` 目录；云端复核真实文件头和 5MB 上限。
- 用户只能读取自己的投稿；客户端不能直读直写 `liuku_submissions`、`liuku_users`、`liuku_feedbacks`。
- 公开接口不返回 `openid`、`appid`、`sourceSubmissionId`、`evidenceFiles`、核验记录或证件内容。
- 非管理员不能读取投稿和核验材料；管理员仅通过后台临时地址查看。

## 管理后台

- 常规菜单有投稿审核，无招聘管理；Excel 页面和下载模板都没有招聘工作表。
- 审核列表只出现商家、房源。缺任一角色必核项或必需材料时，“通过并发布”不可用且服务端拒绝。
- 拒绝必须填写用户可见原因；通过后正式内容保存 `sourceSubmissionId`、核验人、核验时间和复核日期。
- 后台直接录入商家/房源也必须选择主体、上传对应材料并完成清单，不能直接绕过发布门槛。
- 伪造招聘新增、发布、推荐和导入请求均返回 `CHANNEL_DISABLED`；招聘下架操作允许执行。

## 生命周期与迁移

- 已拒绝投稿的 `evidenceRetainUntil` 为拒绝时间一年后。
- 已发布内容下架或删除时，对应投稿的保留期从该时点重新计算一年。
- 每日维护函数到期删除私密原文件、清空文件 ID、记录 `evidencePurgedAt`；公开图片不受影响。
- 清理日志只有材料类型、时间、操作人和结果，不含证件号码或原图。
- 上线前已备份招聘数据；公开招聘统一 `offline`，待审招聘统一拒绝且历史记录未删除。

## 执行命令与真机

- `npm run check:full`
- `npm run test:smoke`
- 管理后台 mock E2E（如本机已安装浏览器）：`npm --prefix admin-web run test:e2e`
- 真机分别完成商家、业主房源、备案中介房源提交；检查图片上传、隐私提示、审核状态与旧版本兼容。
- 上线首周每日检查投稿错误码、图片上传失败、审核积压和异常招聘请求。
